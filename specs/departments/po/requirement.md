# PO — departments

| | |
|--|--|
| Feature | `departments` |
| Title | Danh mục phòng ban |
| changeScope | edit · menu dòng + xóa |

## AC

1. Trên lưới phòng ban, đúp hoặc Ctrl+chuột phải mở menu Xem / Sửa / Xóa.
2. Chọn một dòng thì toolbar có nút Xóa (khi có quyền ghi).
3. Xác nhận xóa thì phòng ban biến khỏi danh sách.
4. Phòng ban đang gán cho nhân sự không xóa được; lưới giữ dòng và báo lỗi.
