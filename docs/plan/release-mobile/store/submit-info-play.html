Android Studio - binary cửa hàng

Repo Linm.RMMS.Mobile.Android, module :app (không Kit). Flavor w3Release. Chi tiết: ANDROID-STUDIO-RELEASE.md

  • Mở :app - Build Variants: w3Release (không w3Debug: bản đồ bật)
  • Thiếu flavor: Settings - Experimental - Configure all Gradle tasks - Sync
  • Ký: keystore.properties + rmms-upload.jks (không debug key)
  • AAB: Generate Bundles hoặc ./gradlew :app:bundleW3Release
  • Output Gradle: app/build/outputs/bundle/w3Release/*.aab
  • BFF Release: https://rmms-mobile-bff.linm-soft.com - STORE_W1=false - targetSdk 36
  • AGP 9.0.1, Gradle 9.1.0, R8 minify + shrink trên release. mapping.txt: app/build/outputs/mapping/w3Release/mapping.txt (Play đọc từ AAB)
  • versionCode +1 mỗi lần tải lên Play (đã dùng 1, 2, 3; Gradle hiện 4). Build local / chụp màn không bắt buộc tăng
  • Chụp listing: emulator-5554 1080x1920, ANDROID_SERIAL một máy, tài khoản rmms-admin (không rmms-002)
