## 3. Executive KPI Index

| # | KPI | Formula | Source | Target |
|---|-----|---------|--------|--------|
| 1 | Overall PCI | AVG(PCI) across all sections | AI Vision | >75 |
| 2 | Defect Resolution Time | AVG(incident.resolvedAt - incident.createdAt) | Incident | <48h (critical) |
| 3 | Patrol Coverage | (km patrolled / km planned) × 100 | Inspection | >95% |
| 4 | SLA Compliance | (incidents met SLA / total) × 100 | Incident | >90% |
| 5 | Budget Utilization | (actual spend / planned budget) × 100 | Contract | <100% |
| 6 | Maintenance Backlog | COUNT(open work orders overdue > 7d) | Maintenance | <10 |
| 7 | Crew Utilization | (hours on task / hours available) × 100 | Attendance + Maintenance | >80% |
| 8 | Citizen Satisfaction | AVG(rating) from resolved incidents | Citizen Portal | >4.0/5.0 |
| 9 | AI Detection Accuracy | (true positives / total AI detections) | AI Vision (weekly audit) | >92% |

## 4. Report Types

### 4.1 Scheduled Reports
```
Generated automatically, delivered via email + in-app.

├── Daily Patrol Summary        (06:00) — previous day's patrol stats
├── Weekly Incident Report      (Mon 08:00) — incident trends, SLA breaches
├── Monthly PCI Trend           (1st, 08:00) — PCI heatmap, degradation rate
├── Quarterly Budget Review     (Q+5d, 08:00) — spend vs plan, forecast
├── Annual Asset Condition      (Jan 5, 08:00) — full asset inventory report
```

### 4.2 On-Demand Reports
```
Generated by user request (Report Service).

├── Section History Report      — all defects/work orders for a road section
├── Contractor KPI Report       — performance scorecard per contractor
├── Cost-Benefit Analysis       — repair cost vs deferral risk
├── Environmental Compliance    — carbon impact, material recycling
└── Custom Export               — user-defined columns, date range, filters
```

### 4.3 Real-time Dashboards
```
Data pushed via SignalR. No page refresh needed.

├── Live Patrol Map              — vehicle positions, recent defects, incidents
├── Incident Heatmap             — cluster of unresolved issues by severity
├── PCI Geographic Distribution  — choropleth map colored by PCI range
└── Budget Burn-down Chart       — cumulative spend vs planned, daily delta
```

## 5. Partner Access Model

External partners (contractors, consultants) receive limited dashboard access:

| Role | Access | Scope |
|------|--------|-------|
| Contractor Supervisor | Work orders assigned to their company | `maintenance.read`, `incident.read` (assigned only) |
| Engineering Consultant | Inspection data for their contract | `ai-vision.read`, `asset.read` (assigned sections) |
| Government Inspector | Read-only all assets | `asset.read`, `dashboard.read` (all) |
| Public (Citizen Portal) | Track own reported incidents | `incident.read` (self-reported only) |

## 6. Embedded Dashboard / iFrame

For integration into existing government portals:

```html
<!-- Embed PCI heatmap into third-party portal -->
<iframe
  src="https://app.rmms.vn/embed/dashboard/pci-heatmap?token=JWT_EMBED&section=QL1A"
  width="100%"
  height="600"
  allow="geolocation"
  sandbox="allow-scripts allow-same-origin">
</iframe>
```

- **Embed tokens:** Short-lived JWT (15 min), scoped to specific sections
- **Refresh:** Parent page requests new token via `/api/v1/embed/token`
- **Rate limit:** 100 embeds per partner per hour
