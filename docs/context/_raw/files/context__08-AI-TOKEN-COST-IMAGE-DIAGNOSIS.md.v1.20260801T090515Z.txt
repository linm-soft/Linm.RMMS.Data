## 1. Cách tính token ảnh (Vision · #3)

GPT-4o **không tính phí theo file MB** — ảnh quy đổi **input tokens** theo độ phân giải + `detail`:

| Chế độ | Ước lượng token / ảnh | Khi dùng |
|--------|----------------------|----------|
| `detail: low` | **~85** tokens | Triage nhanh, lọc ảnh trống / không phải mặt đường |
| `detail: high` ~1024×1024 | **~765** tokens | Chuẩn đoán hư hỏng P1 |
| `detail: high` ảnh lớn (~1920×1080) | **~1.100–1.600** tokens | Camera tuần tra HD |

Thêm mỗi lần gọi:

| Thành phần | Token ước lượng |
|------------|-----------------|
| Prompt hệ thống + hướng dẫn chuẩn đoán (VN/EN, JSON schema) | **300–500** |
| Output JSON (loại hư hỏng, mức độ, mô tả, gợi ý PCI) | **400–800** |

## 3. Bảng chi phí theo khối lượng ảnh (#3)

Giả định **100% ảnh gọi chuẩn đoán** (không triage). Dùng cột B (~$0.009/ảnh).

| Khối lượng ảnh | Mục đích | Token input ≈ | Token output ≈ | **Chi phí GPT-4o** |
|----------------|----------|---------------|----------------|---------------------|
| **1.000** | Smoke test API | ~1,2M | ~0,6M | **~$9** |
| **5.000** | 1 tuyến ngắn | ~5,8M | ~3,0M | **~$45** |
| **20.000** | Đánh giá vs expert | ~23M | ~12M | **~$180** |
| **50.000** | 1–2 tháng 1 đơn vị | ~58M | ~30M | **~$450** |
| **100.000** | Mở rộng | ~117M | ~60M | **~$900** |

### Tối ưu chi phí

1. **Triage `low` trước** → chỉ ~20–40% ảnh nghi ngờ gọi `high`  
2. Batch offline cuối ngày (không realtime từng frame video)  
3. Resize về ~1280 cạnh dài trước khi gửi API  

| Khối lượng thô | Sau triage 30% high | **Chi phí ước lượng** |
|----------------|---------------------|------------------------|
| 20.000 ảnh | 6.000 high + 14.000 low | **~$70** (thay vì ~$180) |
| 50.000 ảnh | 15.000 high + 35.000 low | **~$175** (thay vì ~$450) |

## 5. So sánh P1 online vs P2 local

| Hướng | Chi phí AI (ước lượng) | Ưu | Nhược |
|-------|------------------------|----|------|
| **P1 — online (#3+#8+#10+#16)** | **$50–200** / tháng pilot | Full AI, không train, không GPU | Latency/giá theo volume |
| **P1 — CV API YOLO public (Roboflow…)** | ~**$0.004–0.006**/ảnh | Rẻ hơn Vision một chút | Ít ngữ nghĩa chuẩn đoán |
| **P2 — YOLOv8 local + train** | Đội SV + GPU (`04-PROGRAMS`) | Rẻ biên volume lớn, offline | Dataset VN; thời gian |
| **P2 — XGBoost/ONNX (#8/#10)** | Train + host local | Chủ quyền dữ liệu | Cần lịch sử sạch |
| **P2 — Copilot RAG on-prem (#16)** | Qdrant / GPU nhẹ | On-prem | Ops phức tạp hơn cloud |

**Quyết định đề xuất**

```
P1  = Online full: GPT-4o Vision (#3) + GPT-4o/mini (#8/#10/#16)
    → UAT P/R + chi phí token → Go local / No-go / Pivot
P2  = (nếu muốn local) YOLOv8+train · XGBoost ONNX · RAG on-prem
    → Online chỉ còn fallback case khó
```
