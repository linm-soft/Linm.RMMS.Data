# RMMS — Kịch bản & Plan: **P1** tách khỏi **V2 / P2**

> **SSOT lộ trình.** P1 và V2/P2 tách rời — không trộn scope trong cùng sprint.  
> **AI P1:** mọi phần AI (#3 · #8 · #10 · #16) dùng **online model** — chi tiết model + $ → `08-AI-TOKEN-COST-IMAGE-DIAGNOSIS.md`.  
> **AI P2:** local **ONNX detector** (P2-A/B per `14`) + train · XGBoost/ONNX · RAG on-prem *nếu* Go local — sau gate UAT.

| | **P1** (online AI full) | **V2 / P2** (local nếu muốn) |
|--|-------------------------|------------------------------|
| **Mục tiêu** | Vận hành đủ trên .NET Server (Windows) + **online LLM/API** | Local ONNX detector / ML + GPU khi Go local |
| **AI #3 Kiểm định** | **GPT-4o Vision** (~$0.01/ảnh) | **ONNX detector + SAM** (`14`) + train |
| **AI #8 Dự báo** | **GPT-4o / 4o-mini** online | XGBoost/ONNX local + train |
| **AI #10 Ước lượng** | **GPT-4o** JSON online | Model local + đơn giá |
| **AI #16 Copilot** | **4o-mini** (default) · **GPT-4o** | RAG / on-prem |
| **GPU / đội SV** | **Không** | **Có** (sau gate) |
| **Token** | Alert **~$200/tháng** (Bên A) | Biên phí GPU; online = fallback |
| **Thời lượng gợi ý** | 8–12 tuần | 12–20 tuần (sau gate) |

---

## 1. Nguyên tắc tách (bắt buộc)

1. **P1 không** train detector local / XGBoost, **không** mua A100, **không** đội SV gán nhãn quy mô.  
2. **P2/V2 không** bắt đầu cho đến khi P1 có báo cáo P/R + chi phí token + quyết định go/no-go.  
3. Code P1: adapter `IDefectDiagnoser` → P1 = GPT-4o online · V2 = YoloOnnxDiagnoser (đổi implementation).  
4. App Mobile/Web **giữ UX** — chỉ bổ sung API consumer.  
5. Có thể **giữ P1 online lâu dài** (No-go local).

```
P1 (online full AI) ──UAT + go/no-go──► V2/P2 (local YOLO/ML nếu muốn)
 │                                        │
 └─ Mono + Azure OpenAI                   └─ + GPU / YOLO / đội SV
    (#3+#8+#10+#16 online)                   + online chỉ fallback
```

## 2. Kịch bản P1 — “Full AI online”

### 2.1 Câu chuyện người dùng

1. Tuần đường dùng app (Check-in, Vấn đề, Offline).  
2. Ảnh → API → **GPT-4o Vision** chuẩn đoán → Vấn đề critical (nếu rule).  
3. Dự báo / ước lượng / Copilot qua **online LLM** (không model local).  
4. UAT → báo cáo P/R + token → **giữ online** hoặc **Go local (P2)**.

### 2.2 Phạm vi **IN** (P1)

|---|----------|------------------|
| 1 | Asset | API CRUD + sync; PostGIS cơ bản |

| 3 | AiVision | **GPT-4o Vision** + lưu detection; PCI stub |
| 4–5 | Patrol / Attendance | Check-in API; GPS; offline-batch |
| 6 | Incident | Map Vấn đề; nhận AI → incident |
| 7 | Maintenance | API Công việc khung |

| 18 | Integration | OpenAPI baseline |
| — | Platform | Mono .NET 8 · Auth · Redis · storage · deploy Windows Server (IIS/Kestrel) |

### 2.3 Phạm vi **OUT** (P2 / local — cấm trong P1)

- Train / deploy ONNX detector, SAM GPU, Triton (`14`)  
- Đội SV gán nhãn ≥20k  
- XGBoost/ONNX local (#8/#10), Copilot RAG on-prem (#16)  
- Digital Twin 3D, Maintenance SLA full, Contract / Drone / TOC / Citizen  
- Tách microservice worker AI  

### 2.4 Stack P1

## 3. Kịch bản V2 / P2 — “Local AI (khi đơn vị muốn)”

> Chỉ sau **Go local**. Kế thừa P1; **đổi Diagnoser / Predict / Estimate**, không rewrite mono.

### 3.1 Câu chuyện người dùng

1. Đội SV (+ AI lead) gán nhãn 10 classes → train detector (**P2-A** Apache hoặc **P2-B** Ultralytics Enterprise) → ONNX — SSOT **`14-P2-AI-VISION-STANDARD.md`**.  
2. Inference GPU riêng; mono nhận kết quả.  
3. #8/#10 → XGBoost/ONNX local; #16 → RAG on-prem (tuỳ).  
4. Online GPT chỉ **fallback** case khó.

### 3.2 Phạm vi **IN** (V2/P2)

| Nhóm | Hạng mục | Việc |
|------|----------|------|
| AI local | 3, 8, 10, 16 | ONNX detector+SAM+PCI (`14`); XGBoost local; Copilot on-prem |
| Đội ngũ | — | SV gán nhãn + AI lead |
| Infra | — | GPU worker / Triton |
| Điều hành | 7, 9, 17 | Maintenance full, Command, Dashboard KPI |
| GIS | 2 | Heatmap / Twin 3D |
| Mở rộng | 11–15 | Contract, Drone, TOC, Citizen — backlog |

### 3.3 Phạm vi **OUT V2-core** (V2.1+)

- Self-host LLM full (trừ khi chốt riêng)  
- TOC toàn quốc  
- Data warehouse enterprise  

### 3.4 Stack V2 (bổ sung lên P1)

```
Giữ: Rmms.Api + PostGIS + Redis + storage + Azure OpenAI (fallback)
Thêm:
├── GPU — ONNX detector (P2-A/P2-B per 14) + SAM optional
├── Worker AiVision
├── Đội SV labeling
└── (tuỳ) Qdrant on-prem + XGBoost ONNX
```

> **Chuẩn P2 AiVision:** `14-P2-AI-VISION-STANDARD.md` · server `13` · GPU `10`.
### 3.5 Plan V2 (gợi ý 16 tuần sau gate)

| Giai đoạn | Tuần | Việc |
|-----------|------|------|
| V2-A Dataset | 1–6 | Guideline + SV gán nhãn; ≥20k; mAP nội bộ (`14`) |
| V2-B Model | 5–8 | Train P2-A/B; export ONNX; so sánh vs GPT-4o P1 |
| V2-C Integrate | 7–12 | Worker GPU; `OnnxDetectorDiagnoser`; PCI; event → Incident |
| V2-D Product | 10–16 | Copilot MVP, Dashboard KPI, GIS heatmap; UAT tuyến pilot |

### 3.6 Definition of Done — V2

- [ ] Model custom 10 classes đạt mAP đã chốt với BA  
- [ ] Inference không phụ thuộc GPT-4o cho **mọi** frame (API chỉ fallback)  
- [ ] PCI/IRI trên đoạn pilot  
- [ ] WorkOrder từ defect critical  
- [ ] Chi phí $/km hoặc $/ảnh production đo được và &lt; ngưỡng tài chính
