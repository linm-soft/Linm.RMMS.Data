## 1. Tổng quan

| | |
|--|--|
| Mục tiêu | Camera xe tuần đường phát hiện đối tượng **mới** (chưa có trong CSDL) → AI nhận **loại tài sản/thiết bị** → đề xuất / tự tạo bản ghi: **tọa độ** · **loại thiết bị** · **tuyến đường** (+ đoạn/lý trình khi suy ra được) |
| Persona | Tuần đường · Ban QLDA · GIS |
| Nguồn | Stream / frame camera tuần đường (Patrol) · GPS/IMU gắn xe |
| DoD P1 | Adapter Vision · class thiết bị TS · draft Asset + map pin · confirm UI · cost chung budget AiVision |
| DoD P2 | ONNX class TS · dedupe nearby · confidence gate · GPT fallback |

## 2. Design / UI

| Screen | Pattern | Zones | Gắn app |
|--------|---------|-------|---------|
| Feed / clip tuần đường | Full | Video/ảnh · timeline · GPS track | Patrol Giám sát |
| Detect «TS mới» | Slideout / Full | Bbox · class loại TS · confidence · ảnh crop | Overlay Patrol + AiVision |
| Confirm tạo bản ghi | Modal | Loại · tuyến · tọa độ · mã đề xuất · ảnh | → Asset Thu thập |
| List đề xuất AI | Full | Filter tuyến/ngày/loại · status Draft/Confirmed | Asset / Giám sát TS |
| Bản đồ pin mới | Full | Pin màu «AI new» vs TS đã có | GIS · Giám sát TS |

**AI support (bắt buộc trên demo):** badge `AI` + engine P1/P2 trên card hub và header page.

**P1 UI:** «AI online (GPT-4o Vision) — phát hiện thiết bị mới».  
**P2 UI:** badge `modelVersion` · phân biệt online fallback.

**Mock data:** 3 đề xuất (biển báo, hộ lan đoạn, cột Km) + 1 duplicate nearby (cảnh báo không tạo trùng).

## 3. API

| Method | Path | Mô tả |
|--------|------|-------|
| POST | `/api/v1/ai-vision/detect-assets` | 1 frame / clip → candidates |
| POST | `/api/v1/ai-vision/detect-assets/batch` | Batch theo chuyến tuần đường |
| GET | `/api/v1/ai-vision/asset-candidates?routeId=&from=&to=` | List đề xuất |
| POST | `/api/v1/ai-vision/asset-candidates/{id}/confirm` | Tạo Asset thật (draft→active) |
| POST | `/api/v1/ai-vision/asset-candidates/{id}/dismiss` | Bỏ / false positive |

Adapter: cùng `IDefectDiagnoser` pattern hoặc `IAssetDetector` → P1 `Gpt4oVisionAssetDetector` · P2 `OnnxAssetDetector`.

**Payload tối thiểu (candidate):** `class` (loại TS) · `score` · `bbox` · `lat`/`lng` · `routeId`/`routeCode` · `sectionId?` · `imageUrl` · `patrolTripId` · `modelVersion`.

## 4. Database

| Entity / table | Notes |
|----------------|-------|
| `ai_vision.asset_candidates` | class, score, geom Point, routeId, status Draft/Confirmed/Dismissed, modelVersion |
| Asset (theo type) | Tạo khi Confirm — reuse `asset.md` entities |
| Link | `source=ai-asset-detect` · `candidateId` trên AssetHistory / meta |

Dedupe: `nearby` cùng class trong bán kính cấu hình (vd 15–30 m) → cảnh báo, không auto-create.

## 5. Events

| Event | Consumer |
|-------|----------|
| `asset.candidate.detected` | Notification · GIS overlay |
| `asset.created` (sau confirm) | Gis · Asset list |
