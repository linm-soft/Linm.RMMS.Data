| Method | Path | Mô tả |
|--------|------|-------|
| POST | `/api/v1/copilot/chat` | Message + sessionId |
| GET | `/api/v1/copilot/sessions/{id}` | History |
| POST | `/api/v1/copilot/feedback` | Thumb up/down |

Request skeleton:

```json
{ "sessionId": "…", "message": "Có bao nhiêu ổ gà chưa xử lý?", "locale": "vi" }
```

Auth: JWT · rate limit (`06`). Function-calling SQL **read-only** khi implement.
