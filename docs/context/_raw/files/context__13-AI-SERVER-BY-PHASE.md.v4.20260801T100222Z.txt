## 0. Quy ước

| Loại | Nghĩa trong RMMS |
|------|------------------|
| **Vật lý / on-prem** | Máy trong rack đơn vị hoặc DC thuê cố định (VD: VNPT DMS 1U hiện có) |
| **Cloud managed** | Azure OpenAI, object storage, (tuỳ) cloud GPU VN có SLA |
| **Cloud marketplace** | [Vast.ai](https://cloud.vast.ai/) — GPU thuê theo giờ, P2P, **không** SLA prod |
| **Cấm** | Gắn GPU vào DMS 1U 350W · chạy YOLO 24/7 trên Vast làm endpoint app |

## 1. Ma trận phase → server (đọc một lần)

| Phase | Tên | App / API / DB | AI Vision | Train YOLO | Object ảnh | Ghi chú |
|-------|-----|----------------|-----------|------------|------------|---------|
| **0** | P1 online | **Vật lý** DMS Windows (hoặc VM cố định) | **Cloud** Azure OpenAI GPT-4o | — | Cloud/NAS | **Không GPU** |
| **1** | Gate | Giữ Phase 0 | Giữ Phase 0 | — | — | Chỉ quyết định go/no-go |
| **2** | Dataset + Train | Giữ DMS | Vẫn GPT (baseline) | **Cloud marketplace** Vast 4090 **hoặc** lab GPU vật lý | NAS / MinIO | Burst · tắt sau export |
| **3** | Hybrid infer | DMS + **queue** (Redis trên DMS hoặc VM) | **Worker GPU mới** + GPT fallback cloud | Retrain thỉnh thoảng (Vast) | MinIO/NAS | Worker ≠ DMS |
| **4** | Prod local ổn định | DMS | **GPU cố định** (vật lý box / cloud VN SLA) | Vast hoặc lab khi retrain | Object storage | Online = fallback |

## 2. Chi tiết từng phase

### Phase 0 — P1 online (8–12 tuần)

| Vai trò | Server | Cloud / Vật lý | Spec tối thiểu |
|---------|--------|----------------|----------------|
| API · DB · Redis | **DMS hiện có** (Xeon, 16GB+) | **Vật lý** (hoặc VM DC) | Không cần GPU; nên nâng RAM nếu tải lớn |
| AI Vision #3 | Azure OpenAI | **Cloud managed** | GPT-4o / 4o-mini · alert ~$200/tháng |
| Ảnh gốc | MinIO / S3 / NAS | Cloud **hoặc** NAS vật lý | Không chạy model trên NAS |
| GPU | — | — | **Không thuê / không mua** |

**Không dùng:** Vast.ai, L4, A100, máy YOLO.

---

### Phase 1 — Gate

| Vai trò | Server |
|---------|--------|
| Tất cả | **Giữ nguyên Phase 0** |

Quyết định: **Giữ online** (dừng ở đây) · **Go local** (sang Phase 2) · Pivot prompt.

---

### Phase 2 — Gán nhãn + Train (sau Go local)

| Vai trò | Server | Cloud / Vật lý | Khuyến nghị |
|---------|--------|----------------|-------------|
| App / API | DMS | Vật lý | Không đụng |
| Gán nhãn (CVAT/Roboflow) | Laptop SV + **server nhẹ** hoặc SaaS | Vật lý workstation **hoặc** cloud tool | Data ảnh nên ở storage kiểm soát được |
| **Train detector** | RTX **4090** 24GB · RAM ≥64 · NVMe | **Ưu tiên Cloud marketplace (Vast)** theo đợt | Tắt ngay sau export ONNX |
| Train (phương án B) | PC/GPU lab trường / đơn vị | **Vật lý** | Nếu data không được ra nước ngoài |
| Baseline so sánh | Azure OpenAI | Cloud | Giữ GPT để so P/R vs YOLO |

**Cấm Phase 2:** Infer production 24/7 trên cùng máy Vast đang train.

---

### Phase 3 — Hybrid (YOLO lọc + GPT khó)

| Vai trò | Server | Cloud / Vật lý | Spec |
|---------|--------|----------------|------|
| API · DB | DMS | Vật lý | Queue job (Redis) |
| **GPU Worker infer** | Máy **mới tách** | **Vật lý GPU box** *hoặc* **Cloud VN có SLA** (không Vast 24/7) | Tier Pilot→Prod: T4/L4 16–24GB · RAM ≥32–64 · NVMe (xem `10` §3) |
| GPT fallback | Azure OpenAI | Cloud | Chỉ low-confidence / class khó |
| Retrain | Vast / lab | Burst cloud hoặc vật lý | Định kỳ |

**Kiến trúc:**

```
[DMS vật lý — API/DB] --queue--> [GPU Worker cố định] --detections--> DMS
         |                              ^
         +---- fallback ----> [Azure OpenAI cloud]
```

---

### Phase 4 — Prod local ổn định

| Vai trò | Server | Cloud / Vật lý | Tier `10` |
|---------|--------|----------------|-----------|
| API | DMS | Vật lý | App only |
| Infer chính | **1× L4 24GB** (chuẩn) | **Vật lý** hoặc **cloud managed VN** | Prod chuẩn |
| Cao tải | 1–2× L40S / 2× L4 | Vật lý / cloud SLA | Prod cao tải |
| Train / retrain | Vast 4090 hoặc lab | Marketplace / vật lý | Không phục vụ API |
| GPT | Azure | Cloud | Fallback |

## 3. Quyết định nhanh: Cloud hay Vật lý?

| Câu hỏi | → Chọn |
|---------|--------|
| Mới bắt đầu / UAT AI? | **Vật lý DMS** + **Cloud GPT** (Phase 0) |
| Train 1–2 tuần, data được xuất? | **Vast cloud** (Phase 2) |
| Data đường bộ **cấm** ra nước ngoài? | Train **vật lý lab** · Infer **DC VN** |
| Infer tuần đường 24/7? | **GPU cố định** (vật lý hoặc cloud VN SLA) — **không Vast** |
| Tiết kiệm capex trước khi chốt P2? | Giữ Phase 0 online lâu hơn |

## 4. Checklist mua / thuê

### Phase 0
- [ ] DMS chạy API ổn (không gắn GPU)
- [ ] Azure OpenAI key + budget alert
- [ ] Object storage ảnh

### Phase 2
- [ ] Tài khoản Vast (hoặc lab 4090)
- [ ] Filter: 4090 · RAM≥64 · NVMe · on-demand
- [ ] Pipeline export ONNX → bàn giao Dev

### Phase 3–4
- [ ] Host GPU **tách** DMS (PSU/chỗ/nhiệt OK — `10` §5)
- [ ] Queue + worker + monitoring GPU
- [ ] VPN/firewall chỉ DMS → worker
- [ ] GPT vẫn bật fallback
