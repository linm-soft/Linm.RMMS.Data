| Lớp | Ý nghĩa | Module gợi ý | Persist |

## 2. API — CSDL biểu 1–12

### 2.1 Pattern CRUD (mọi loại)

```
GET    /api/v1/infra/{resource}?road=&province=&kmFrom=&kmTo=&search=&page=&pageSize=
GET    /api/v1/infra/{resource}/{id}
POST   /api/v1/infra/{resource}
PUT    /api/v1/infra/{resource}/{id}
DELETE /api/v1/infra/{resource}/{id}          # soft-delete
GET    /api/v1/infra/{resource}/export        # Excel = đúng cột biểu mẫu
POST   /api/v1/infra/{resource}/import        # import Excel biểu
```

| `{resource}` | Biểu |
|--------------|------|
| `pavement-sections` | 1 |
| `bridges` | 2 |
| `road-tunnels` | 3 |
| `culverts` | 4 |
| `ditches` | 5 |
| `underpasses` | 6 |
| `traffic-safety` | 7 (list + `?type=`) |
| `boundary-markers` | 8 |
| `retaining-walls` | 9 |
| `shoulders-fences` | 10 |
| `lighting-systems` | 11 |
| `green-assets` | 12 |

### 2.2 Spatial / báo cáo

```
GET /api/v1/infra/geojson?layers=bridges,culverts&bbox=
GET /api/v1/reports/infra/form/{formNo}?road=&province=&asOf=
# formNo = 1..12 — trả rows đúng layout biểu in
```

### 2.3 Liên kết GIS vẽ Google

Khi vẽ trên map (`gis-draw-google`): `layerCode` map → `{resource}` ở trên; `POST /api/v1/gis/drawings` commit → `POST /api/v1/infra/{resource}`.

## 3. Catalog — 8 mẫu sổ BDTX (vận hành)

| Mẫu | Tên sổ | Căn cứ | Entity / aggregate | Module |
|-----|--------|--------|-------------------|--------|
| 1 | Nhật ký tuần đường | TT 41 Phụ lục VIII | `PatrolLogBook` + `PatrolLogEntry` | Patrol |
| 2 | Trực BĐGT / bão lụt / hotline | TCVN 14182 §4.2.3 | `DutyLog` + `DutyShiftEntry` | Patrol/Ops |
| 3 | Trực chốt | Thực tế | `CheckpointDutyLog` + entries | Patrol |
| 4 | Tổng hợp đếm xe (+ TNGT) | TT 41 · TCVN 14182 Phụ lục C | `TrafficCountSummary` · `AccidentSummary` | Report/IoT |
| 5 | Quản lý cầu/hầm (lý lịch + phiếu KT) | TT 41 · TCVN | `BridgePassport` · `BridgeInspection` | Asset/Maintenance |
| 6 | Hành lang ATĐB + giấy phép TC | TT 41 điểm l | `RowViolation` · `ConstructionPermit` | Incident/Compliance |
| 7 | Ghi chép kết quả BDTX | TT 41/72 Mẫu PL III | `MaintenanceWorkLog` | Maintenance |
| 8 | Nhật ký tuần kiểm | TT 41 Điều 20 · PL VIII | `InspectionLogBook` + `InspectionEntry` | Patrol (supervisor) |

### 3.1 Mẫu 1 — Nhật ký tuần đường

**Header sổ:** `BookNo`, `Contractor`, `KmFrom`, `KmTo`, `RoadCode`, `PatrolStaff`, `StartDate`, `EndDate`

**Entry:**

| Cột | Type |
|-----|------|
| `CheckedAt` | timestamptz | Giờ ngày kiểm tra |
| `LocationText` / `Km` | … | Vị trí, lý trình sự cố/vi phạm |
| `WeatherAndEvent` | text | Thời tiết + diễn biến |
| `OnSiteAction` | text | Đã xử lý tại chỗ |
| `SupervisorNote` | text | Nhận xét người nhận BC |
| `SupervisorSignedAt` | timestamptz | |
| `SketchMediaIds` | uuid[] | Vẽ minh họa |
| `Notes` | text | |

```
POST /api/v1/patrol-logs/books
POST /api/v1/patrol-logs/books/{bookId}/entries
GET  /api/v1/patrol-logs/entries?road=&from=&to=
```

### 3.2 Mẫu 2 — Trực BĐGT / bão / hotline

**Entry:** `Date`, `Shift`, `StaffName`, `DutyContent`, `Resolution`, `SignedAt`

```
POST /api/v1/duty-logs
GET  /api/v1/duty-logs?type=traffic|storm|hotline&from=&to=
```

### 3.3 Mẫu 3 — Trực chốt

**Header:** `CheckpointName`, `StationKm`, `KmFrom`, `KmTo`, `RoadCode`, `Direction`, `ShiftNo`  
**Entry:** `Content`, `At`, `Complied` bool, `Result`, `HandoverFrom`, `HandoverTo`

```
POST /api/v1/checkpoint-duties
POST /api/v1/checkpoint-duties/{id}/entries
```

### 3.4 Mẫu 4 — Đếm xe + TNGT

**TrafficCountSummary** — 1 row / trạm / kỳ; cột phân loại xe (xem Excel/Word — ~18 class xe + `TotalCars`).

**AccidentSummary:** `RoadCode`, `Fatalities`, `Injuries`, `DamagedVehicles`, `Notes`, `Period`

```

GET  /api/v1/traffic-counts?station=&quarter=&year=

```

### 3.5 Mẫu 5 — Lý lịch cầu + Phiếu kiểm tra cầu
