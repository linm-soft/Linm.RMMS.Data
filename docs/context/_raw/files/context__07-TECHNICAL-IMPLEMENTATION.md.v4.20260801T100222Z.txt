## 0. Quy ước chung cho team

### 0.1 Tech stack bắt buộc

| Lớp | Công nghệ | Ghi chú |
|-----|-----------|---------|
| Backend host | **C# .NET 8** ASP.NET Core Web API | 1 process `Rmms.Api` |
| Module layout | `src/Modules/{Name}/` | Controllers · Application · Domain · Infrastructure |
| ORM | EF Core 8 + Npgsql | `ApplyUtcDateTimeConvention()` |
| Spatial | **PostGIS** (NetTopologySuite) | Asset, GIS, Patrol |
| Time-series | **TimescaleDB** | GPS track, IoT, sensor |
| Cache / realtime | Redis + **SignalR** | Dashboard, notification |
| Object storage | MinIO (S3 API) | Ảnh, video, point cloud |
| Queue (in-process → scale) | MassTransit + RabbitMQ | Event giữa modules |
| Auth | JWT access 15' + refresh HttpOnly | Claim `company_id` / `tenant_id` |
| API | `api/v1/...` + OpenAPI/Swagger | Bắt buộc |
| AI Vision | ONNX/TensorRT detector + SAM (`14`) | Triton hoặc ONNX Runtime |
| AI Copilot | GPT-4o (Azure OpenAI) + Qdrant RAG | Function-calling SQL read-only |
| Predictive | XGBoost → ONNX → ML.NET | Dự báo xuống cấp / ước lượng |
| FE (giữ app) | Mobile + Web RMMS hiện có | Chỉ bổ sung API consumer |
| FE (nâng cấp) | React 18 + TS (tuỳ module) | Dashboard / Copilot / GIS 3D |

## Hạng mục 3 — AI kiểm định mặt đường (`AiVision`)

### Nghiệp vụ (docx)
Thu thập: Camera AI, Line Scan, 360, GPS, IMU.  
Nhận diện: ổ gà, nứt dọc/ngang/mai rùa, bong bật, lún vệt bánh, chảy nhựa, vá đường, sạt lở, hư mép.  
Tính: **PCI, IRI, SCI**, mức hư hỏng, mức ưu tiên sửa chữa.

### Classes detect (bắt buộc train — P2)

`pothole`, `longitudinal_crack`, `transverse_crack`, `alligator_crack`, `bleeding`, `raveling`, `rutting`, `patching`, `edge_damage`, `landslide`

> **P2 chuẩn hóa (SSOT):** `14-P2-AI-VISION-STANDARD.md` — mặc định **P2-A** Apache (YOLOX / RTMDet / RT-DETR → ONNX); **P2-B** Ultralytics + **Enterprise**. Không dùng Ultralytics AGPL cho prod đóng.

### Công nghệ
| Thành phần | Tech |
|------------|------|
| Detect | **ONNX/TensorRT detector** (P2-A Apache **hoặc** P2-B Ultralytics Enterprise) |
| Segment | **SAM** (Apache) mask → m² — optional |
| Edge (nếu có) | Jetson + MQTT |
| Cloud | Module `AiVision` trong mono (+ Worker khi scale) |
| Storage raw | MinIO |
| Index | `ai_vision.detections`, `ai_vision.pci_history` |

### Đội training (sinh viên) — bắt buộc
| Vai trò | Việc |
|---------|------|
| **Đội SV gán nhãn** | Thu ảnh hiện trường (tuần tra/drone) → gán nhãn 10 classes theo guideline → QA chéo |
| **AI/ML lead (mentor)** | Guideline, review mAP, train detector (P2-A/B), xuất **ONNX** bàn giao Dev |
| **Dev outsource** | Chỉ tích hợp inference (Triton/ONNX Runtime) + API — **không** thay gán nhãn |
| **BA / nghiệp vụ** | Xác nhận định nghĩa class theo đường VN + UAT tuyến pilot |

**Mục tiêu dataset P2:** ≥ **20.000** ảnh đã gán nhãn, cân bằng theo 10 classes. Không có dataset VN → AI Vision local không đạt độ chính xác vận hành.

**P1 (online full):** mọi AI dùng cloud API — **GPT-4o Vision** (#3) · **GPT-4o / 4o-mini** (#8 · #10 · #16). ~**$0.01/ảnh** chuẩn đoán; pilot tháng **~$50–200** (alert **$200**). **Không** train detector local trong P1.  
Chi tiết model + $: `08-AI-TOKEN-COST-IMAGE-DIAGNOSIS.md` §0.  
**P2 (nếu muốn local):** theo **`14-P2-AI-VISION-STANDARD.md`** · GPU `10` · server `13`.

### API
```
POST /api/v1/ai-vision/detect
POST /api/v1/ai-vision/batch
POST /api/v1/ai-vision/segment
POST /api/v1/ai-vision/calculate-pci
GET  /api/v1/ai-vision/defects?sectionId=&from=&to=
GET  /api/v1/ai-vision/pci-history/{sectionId}
```

### Tasks team
1. Model registry + Triton/ONNX hosting (Dev — sau khi nhận ONNX từ đội SV)  
2. Pipeline detect → segment → severity → PCI (ASTM D6433)  
3. Event `defect.detected` → Asset/GIS/Incident  
4. Batch nhận ảnh realtime **và** upload cuối ngày  
5. Dashboard xem defect trên map  
6. **P2 (sau gate local):** theo `14-P2-AI-VISION-STANDARD.md` — đội SV gán nhãn + train detector P2-A/B — bàn giao ONNX; P1 chỉ online Vision
