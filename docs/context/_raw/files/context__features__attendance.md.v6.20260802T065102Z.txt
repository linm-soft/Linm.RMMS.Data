## 2. Design / UI

| Screen | Pattern | Zones | Ghi chú |
|--------|---------|-------|---------|
| Check-in (Mobile) | Full (giữ) | GPS · nội dung · offline | Cùng màn Patrol |
| Báo cáo checkin (Web) | Full | Filter tuyến/ngày · bảng · Xuất Excel | Guide § Báo cáo checkin |
| Cấu hình zone (Web, optional) | Slideout | Polygon tuyến · bán kính | Admin |

**Mock data:** 1 tuyến · 3 điểm/ngày · 5 ngày · % đúng tuyến.

**UI pattern:** Gộp Check-in; báo cáo = Full page.

## 3. API

Base: `api/v1/attendance` (hoặc nested Patrol)

| Method | Path | Mô tả |
|--------|------|-------|
| GET | `/attendance/report?from=&to=&routeId=&userId=` | Báo cáo công |
| GET | `/attendance/summary?period=week\|month` | Tổng hợp |
| POST | `/attendance/validate-checkin` | Kiểm tra zone (server) |
| GET | `/attendance/zones?routeId=` | Geo-fence |

Auth: JWT · tenant. Check-in write vẫn qua `/api/v1/patrols/.../check-ins`.

## 4. Database

| Entity | Key columns | Notes |
|--------|-------------|-------|
| AttendanceLog | Id, UserId, CheckInId, RouteId, At, InZone | Derived / materialize |
| GeoFence | Id, RouteId, Geom | PostGIS polygon / buffer |

Indexes: `(UserId, At)` · GIST `Geom`.
