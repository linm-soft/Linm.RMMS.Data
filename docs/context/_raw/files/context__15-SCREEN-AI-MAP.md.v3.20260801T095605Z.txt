## 4. Luồng nghiệp vụ end-to-end (chuẩn hóa)

```
Check-in / GPS track (Mobile)
    → Patrol API + Timescale
Ảnh hiện trường (Mobile Vấn đề)
    → AiVision detect (P1 GPT-4o / P2 ONNX)
    → defect.detected → Incident (critical)
Incident / Vấn đề (Mobile+Web)
    → Assign · Comment · SLA stub
    → AI Estimate (P1 JSON) → Work Order (P2 Maintenance)
Công việc (Mobile+Web)
    → Tiến độ · ảnh nghiệm thu → AssetHistory
GIS overlay (Web Giám sát)
    → Asset · Incident · PCI heatmap
Copilot / Predict / Dashboard (Web)
    → Đọc aggregation · NL query (P1 online)
```
