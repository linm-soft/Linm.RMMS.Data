# RMMS — AI Road Infrastructure Platform Overview

## 1. What is RMMS?

RMMS (Road Infrastructure Management & Monitoring System) is a comprehensive AI-powered ecosystem that
digitizes the entire lifecycle of road infrastructure asset management — from real-time data collection,
AI-driven damage detection, GIS-based visualization, and predictive maintenance to command-center
decision support. It serves Departments of Transport (Sở GTVT), project management boards (Ban QLDA),
maintenance contractors, and field crews.

> RMMS = AI Vision + GIS Digital Twin + IoT Ingestion + Workflow Engine + AI Copilot + 18 Business Modules

## 2. Server Infrastructure for AI/LLM (Required)

> **Note:** All field hardware (cameras, drones, vehicles, tablets, sensors) is assumed
> already available from existing operations. This section covers ONLY the server-side
> compute required to run AI models and LLM services.

## 3. Core Principles

| # | Principle | Technical Meaning |
|---|-----------|-------------------|
| 1 | AI-First Inspection | Computer Vision replaces manual visual inspection; YOLOv8 + SAM on Edge |
| 2 | Single Source of Truth | Every asset, defect, work order lives in one geo-referenced database |
| 3 | Real-time + Offline Dual Mode | Live 4G/5G streaming for patrol vehicles; offline buffer + EOD sync for remote areas |
| 4 | GIS-Native | PostGIS spatial engine; every entity has lat/lng; 2D/3D map as primary UX |
| 5 | Predictive Maintenance | ML models (XGBoost) forecast degradation from traffic, weather, material age |
| 6 | Natural Language Access | GPT-4o Copilot allows "Which section is degrading fastest?" queries |
| 7 | Open by Design | RESTful API + Webhook for ERP/CMMS/ITS/ETC — extend existing data via API |
| 8 | Modular Monolith First | 14 domain modules in **one** .NET host; split workers/microservices only when scaling |
| 9 | Existing App First | Keep current Mobile/Web RMMS (Check-in, Issues, Tasks, Assets, Monitoring, Offline) — see user guide docx |
