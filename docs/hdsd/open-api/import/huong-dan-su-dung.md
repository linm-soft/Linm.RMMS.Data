## Import tài sản KCHTTạo mớiKind B

**Mục đích:** mở và tra cứu Import tài sản.

**Cách thực hiện:**

1. Vào menu **Import tài sản**.
2. Điền điều kiện lọc nếu cần.
3. Nhấn **Tạo mới** / **Thêm** khi cần lập bản ghi, hoặc kích dòng để xem.
